## JVM과 실행 흐름

JVM 대상 언어의 소스 코드는 컴파일을 거쳐 JVM이 실행할 수 있는 바이트코드가 될 수 있다.

`소스 코드 → 컴파일 → JVM 바이트코드 → JVM → OS/CPU`

JVM(Java Virtual Machine)은 바이트코드를 실행하는 가상 머신이다. 운영체제의 프로세스, 메모리, 스레드 등의 기능을 사용하면서 애플리케이션 코드를 실행한다.

## JDK와 런타임

JDK는 Java Development Kit의 약자다. 컴파일러와 실행·진단 도구 등 JVM 생태계에서 개발에 필요한 구성 요소를 제공한다.

런타임(runtime)은 프로그램이 실제 실행되는 시점과 실행 환경을 뜻한다. JVM 애플리케이션은 실행 시 JVM 계열 런타임이 필요하다. 다만 배포 방식에 따라 전체 JDK가 아니라 실행에 필요한 구성만 포함한 런타임 이미지를 사용할 수도 있다.

## 구조 관점

백엔드 프레임워크는 HTTP 요청 처리, 객체 생성과 연결, 설정, 데이터 접근 연동 같은 서버 기능을 제공한다. 프론트엔드 화면을 만드는 도구와 역할이 다르다.

## 공격자 관점

런타임과 프레임워크의 버전 및 의존성은 공격 표면의 일부다. 알려진 취약점이 있는 구성 요소가 남아 있으면 애플리케이션 자체 로직과 별개로 공격 경로가 생길 수 있다.
