## 일일 최소 단위
- [ ] 계획·기록: 당일 수행 결과를 활동별로 닫고 취침 전 다음날 상태 결정
- [ ] 운동: 퇴근 후 운동 코치에게 당일 운동을 받아 1단위 수행
- [ ] 직무 브리핑: 자동 생성 결과 확인 후 `/take ITEM_ID` 또는 `/no-action`으로 닫기
- [ ] 정보보안기사: 최소 1페이지 7회독 → 자료 폐쇄 회상 → 보안 코치 검증
- [ ] 버그바운티: 퇴근 후 `EXPLORE-1` 또는 진행 중인 `VERIFY/REPORT` 1단위
- [ ] 철학 독서: 읽기 → 기억에 남은 것 1개 → 이유 → 기존 경험·생각·지식과 연결
- [ ] 문학 독서: 읽기 → 기억에 남은 것 1개 → 이유 → 기존 경험·생각·지식과 연결
- [ ] 과학 독서: 읽기 → 기억에 남은 것 1개 → 이유 → 기존 경험·생각·지식과 연결
- [ ] 영어: 문법 포인트 1개 → 폐쇄 회상 → 신규 문장 적용 → PASS/REVIEW
- [ ] 투자 오전: 자동 분석 결과를 확인하고 매매/관망 판단
- [ ] 투자 저녁: 오전 가설과 실제 시장·행동을 비교해 하루 투자 사이클 닫기

## 실행 배치
- 출근 버스 학습 가능 90분: 직무 브리핑 → 투자 오전 판단 → 정보보안기사 최소 1단위 → 영어 문법 1단위 → 철학·문학·과학 독서 최소 단위 순으로 닫는다.
- 퇴근 버스 학습 가능 90분: 출근길에 남은 최소 단위를 먼저 닫고, 모두 완료됐으면 정보보안기사 추가 단위에 집중한다.
- 퇴근 후: 운동 1단위 → 버그바운티 1단위 순으로 수행한다.
- 20:00 이후 투자 저녁 자동 결과가 준비되면 당일 투자 복기를 닫는다. GitHub Actions 지연 시 실제 결과가 생성된 뒤 확인한다.
- 취침 전: 당일 미완료 항목과 다음 상태를 확인하고 2026-09-02 계획으로 넘긴다.
