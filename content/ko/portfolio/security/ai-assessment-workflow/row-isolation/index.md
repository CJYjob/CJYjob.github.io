## 입력 패킷을 나눠도 판정자의 문맥은 남아 있었다

여러 행을 판정하는 작업에서 한 행의 정보만으로 판단하도록 요구했다. 피더는 행별 자료를 만들었지만 실제 판단은 하나의 메인 세션에서 여러 행을 보며 진행됐다. 또한 일부 결과는 다른 행이나 다른 보고서의 선례를 스크립트로 복사했다. 입력 분리는 실행됐지만 판정 컨텍스트의 격리와 동일하지 않았다.

명시적으로 판정을 복사한 동작과 모델이 앞 문맥에 영향을 받는 현상도 구분해야 한다. 둘을 하나의 “AI 편향”이라고 설명하면 해결 방법을 잘못 고를 수 있다.

## 새 합성 실험의 질문

이번에는 가상 행 5개를 만들고, 한 실행에서 순서대로 판정하는 A안과 행마다 새 실행을 사용하는 B안을 비교했다. 동일 항목의 값이 서로 다르거나, 값 수집에 실패했거나, 앞 장비와 같다는 답변만 있는 입력을 포함했다. 정답은 모델 실행 전에 정했다.

| 조건 | 실행 방식 |
| --- | --- |
| A | 5개 행을 한 실행에 제공 |
| B | 각 실행에 1개 행만 제공 |
| A2·B2 | 다른 행 참조를 금지하는 기준 문구를 뺀 변형 |

실험은 Claude Code 서브에이전트 기능으로 조건별 1회 실행했다. B의 각 실행은 다른 행의 응답을 전달받지 않았지만 공통 작업 지침은 함께 받았다. 완전히 빈 컨텍스트라는 뜻은 아니다. 모델과 실행 방법의 전달받은 기록은 다운로드 묶음의 README에 남겼으며, 샘플링 설정은 확인하지 못했다.

## 결과: 모든 조건이 정답이었다

저장된 응답을 재채점한 결과 16개 행 판정이 사전 정답과 일치했다. 응답에 명시된 다른 행 참조와 정해 둔 문자열 검사에서도 참조 흔적이 나오지 않았다. **이 입력에서는 A와 B의 차이가 관찰되지 않았다.** 격리가 효과적이었다거나 필요 없다는 결론을 낼 수 없다.

| 확인한 것 | 아직 확인하지 못한 것 |
| --- | --- |
| 짧고 신호가 분명한 입력에서의 응답 | 긴 대화와 많은 행에서의 흔들림 |
| 저장된 JSON의 정답 일치 | 조건별 반복 실행 분포 |
| 응답의 제한된 참조 표식 | 모델 내부에서 실제로 어떤 정보가 영향을 줬는지 |
| 새 모델 실행을 위한 프롬프트 | 과거 스크립트의 명시적 선례 복사 방지 |

## 재현 자료

[합성 입력·프롬프트·응답·채점 코드 ZIP](/examples/row-isolation.zip)을 풀고 다음 명령을 실행하면 저장된 응답을 다시 채점한다. 모델을 새로 호출하지 않는다.

```text
python -X utf8 -I grade.py
```

새 실험을 하려면 README의 순서대로 각 프롬프트를 새 대화에 제공하고 출력 파일을 교체해야 한다. 채점기는 문자열 규칙을 사용하므로 숨은 정보 참조를 완전히 탐지하지 못한다. 과거 고객사 데이터나 패킷은 포함하지 않았다.
