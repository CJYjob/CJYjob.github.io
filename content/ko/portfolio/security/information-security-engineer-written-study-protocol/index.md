## 목적

시험까지 약 1개월 남은 상태에서 큰 분량을 한 번에 강제하지 않고, **하루 최소 1페이지**를 출발점으로 하여 5개 필기 과목을 병렬 관리한다. 핵심 목표는 다음 세 가지다.

1. 시작 마찰을 없애 매일 최소 단위를 끊지 않는다.
2. 특정 과목만 진도가 앞서지 않도록 과목별 진도 포인터를 독립 관리한다.
3. 시험이 가까워질수록 교재 회독 중심에서 기출문제와 과목별 점수 검증 중심으로 전환한다.

## 시험 제약

한국방송통신전파진흥원(KCA) 국가기술자격검정의 정보보안기사 안내 기준 필기시험은 다음 5과목이다.

1. 시스템보안
2. 네트워크보안
3. 어플리케이션보안
4. 정보보안일반
5. 정보보안관리 및 법규

필기는 과목당 20문항, 총 100문항, 객관식 4지선다형 2시간 30분이며, **매 과목 40점 이상이면서 전 과목 평균 60점 이상**이어야 한다.

공식 확인: <https://www.cq.or.kr/qh_quagm01_020.do>

따라서 이 프로토콜은 평균점수만 높이는 방식이 아니라 **가장 약한 과목의 과락 위험을 먼저 낮추는 방식**으로 동작한다.

## 1. 상태 모델

각 과목은 서로 독립된 상태를 가진다.

- `next_page`: 다음 신규 학습 페이지
- `completed_new_units`: 통과한 신규 1페이지 수
- `review_queue`: 복습 필요 페이지 목록
- `last_touched`: 마지막 학습 일자
- `latest_fresh_score`: 처음 푼 20문항 기준 최근 점수
- `score_band`: 위험 / 경계 / 안정 / 안전

전체 시스템은 다음 상태를 추가로 가진다.

- `rotation_cursor`: 다음 신규 진도 대상 과목
- `current_round`: 5과목 회전 번호
- `phase`: 시험일까지 남은 기간에 따른 학습 단계

신규 진도 수의 과목 간 격차는 원칙적으로 **1단위 이내**로 유지한다. 즉 어느 과목의 `completed_new_units`가 가장 뒤처진 과목보다 2 이상 앞서게 되는 신규 진도는 허용하지 않는다.

## 2. 기본 과목 회전

기본 회전은 다음 순서다.

**시스템보안 → 네트워크보안 → 어플리케이션보안 → 정보보안일반 → 정보보안관리 및 법규 → 다시 시스템보안**

하루 최소 수행량은 이 회전에서 선택된 **1단위**다.

추가 시간이 있을 때는 특정 과목을 계속 밀지 않고 다음 규칙으로 확장한다.

1. 복습 필요 항목이 있으면 복습을 우선한다.
2. 신규 진도라면 현재 5과목 회전에서 아직 수행하지 않은 과목을 우선한다.
3. 5과목이 모두 한 번씩 수행된 뒤에만 다음 회전으로 넘어간다.
4. 신규 진도 격차가 2단위 이상 벌어지는 선택은 금지한다.
5. 기출 점수 위험 과목은 추가 학습·문제 세트 우선권을 갖지만 다른 과목의 기본 회전 자체를 삭제하지 않는다.

## 3. 신규 1페이지 기본 단위

### 사용자 수행

1. 코치가 지정한 과목과 페이지를 연다.
2. 해당 1페이지를 7회독한다.
3. 책을 덮는다.
4. 원문을 보지 않고 이해한 내용을 스스로 설명한다.
5. 코치에게 다음 세 항목만 전달한다.

```text
과목: 시스템보안
페이지: p.123
회상: 내가 기억해서 설명한 내용
```

위 형식으로 제출하면 기본적으로 `7회독 완료 = true`로 기록한다. 7회독을 끝내지 못했을 때만 `7회독 미완료`라고 덧붙인다.

### 7회독 내부 방식

기존 7회독 원칙을 유지하되 기록 부담을 늘리지 않는다.

1. 핵심 단어 중심으로 구조 훑기
2. 단어·숫자·표·그림 확인
3. 빠르게 전체 흐름 읽기
4. 문장과 관계를 정독
5. 정독하며 머릿속 요약
6. 다음 내용을 예측한 뒤 정독하고 머릿속 요약
7. 예측하면서 최종 정독

읽는 동안 별도 필기는 강제하지 않는다. 외부화는 7회독 종료 후의 **폐쇄형 회상**에서만 한다.

## 4. 코치 검증 규칙

코치는 원문 또는 제공된 학습 범위를 기준으로 회상 내용을 비교한다.

검증 대상은 단순 단어 일치가 아니라 다음 요소다.

- 핵심 개념의 정의와 역할
- 원인과 결과의 관계
- 조건·범위·예외
- 서로 헷갈리기 쉬운 개념의 구분
- 시험 답을 바꿀 수 있는 숫자·순서·법적 요건

판정은 **통과 / 복습 필요** 두 가지로 단순화한다.

### 통과

- 시험 정답을 바꿀 수준의 핵심 오류가 없다.
- 핵심 개념 간 관계를 설명할 수 있다.
- 사소한 표현 차이나 부가 예시 누락만 있다.

### 복습 필요

다음 중 하나라도 있으면 복습 필요다.

- 핵심 정의를 반대로 이해함
- 원인·결과 또는 주체·대상을 뒤바꿈
- 중요한 조건이나 예외를 누락함
- 시험 답을 바꿀 수 있는 숫자·순서·법규 요건을 틀림
- 페이지의 주제를 설명했지만 핵심 논리 구조가 빠짐

코치의 응답 형식은 다음으로 고정한다.

```text
판정: 통과 | 복습 필요
오류·누락: 핵심만 짧게
상태: 완료 → 다음 신규 페이지 | 복습 큐 등록 → 동일 페이지 재검증
```

정확한 원문 대조를 위해 코치가 해당 교재 페이지를 볼 수 있어야 한다. 교재 PDF가 제공되어 있으면 그것을 사용하고, 그렇지 않으면 해당 페이지 사진 1장만 추가로 받는다. 공개 자산에는 저작권이 있는 교재 원문 전체를 저장하지 않고 사용자의 회상·오류·검증 결과만 남긴다.

## 5. 복습 큐

신규 페이지가 `복습 필요` 판정을 받으면 다음 상태가 된다.

- 해당 페이지는 완료 처리하지 않는다.
- 과목의 `next_page`를 전진시키지 않는다.
- 페이지를 `review_queue`에 넣는다.
- 다음 학습 시 신규 진도보다 복습을 우선한다.

복습 방법도 동일하다.

1. 같은 페이지 7회독
2. 책을 덮음
3. 다시 회상
4. 코치 재검증

통과하면 `review_passed = true`로 기록하고 그때 신규 포인터를 다음 페이지로 이동한다.

복습 실패가 반복되면 단순 재회독만 무한 반복하지 않는다. **2회 연속 실패 시 고착 오류**로 보고 코치가 틀린 구조만 짧게 교정한 후 다음 재검증을 시행한다.

## 6. 과락 방지 우선 규칙

교재 진도는 5과목을 균등하게 돌리되, 기출 점수가 생기기 시작하면 다음 안전 구간을 사용한다.

- **위험:** 20문항 기준 0~11개 정답, 즉 60점 미만
- **경계:** 12~13개 정답, 60~65점
- **안정:** 14~15개 정답, 70~75점
- **안전:** 16개 이상 정답, 80점 이상

실제 과락선은 40점이지만 운영상 목표는 더 높게 둔다.

- 최소 운영선: 모든 과목 최근 신선 기출 세트 **60점 이상**
- 최종 안전 목표: 모든 과목 60점 이상, 가능하면 **70점 이상**

위험 과목이 있으면 추가 시간의 우선순위는 다음과 같다.

1. 위험 과목의 오답 관련 복습
2. 위험 과목의 신선한 20문항 세트
3. 가장 진도가 뒤처진 과목의 신규 1페이지
4. 기본 회전의 다음 과목

단, 위험 과목 때문에 다른 과목이 영구 중단되지 않도록 기본 5과목 회전 포인터는 계속 보존한다.

## 7. 기출 점수 검증 규칙

점수 검증에는 **처음 푸는 문제만** 사용한다.

- 재풀이 점수는 학습 확인용이지 실력 점수로 사용하지 않는다.
- 가능하면 실제 시험과 동일하게 과목별 20문항 단위로 푼다.
- 과목별 20문항 점수와 틀린 개념을 함께 기록한다.
- 오답은 관련 페이지 또는 개념을 복습 큐에 연결한다.

문제를 틀렸다고 무조건 교재 전체를 다시 읽지 않는다. 틀린 이유를 다음 네 유형 중 하나로 분류한다.

- 개념 미기억
- 개념 혼동
- 조건·예외 누락
- 문제 해석 실수

앞의 세 유형은 복습 큐에 연결한다. 단순 문제 해석 실수는 별도 오답 패턴으로 기록하되 교재 페이지 복습을 자동 강제하지 않는다.

## 8. 시험일까지 단계 전환

### T-30 ~ T-22: 교재 적응·병렬 포인터 구축

- 중심: 교재 7회독 + 폐쇄형 회상
- 하루 최소: 1페이지
- 새 진도는 5과목 순환
- 추가 시간이 있으면 같은 회전의 다음 과목으로 확장
- 기출은 진단 목적으로 천천히 도입
- 이 구간이 끝날 때까지 가능하면 각 과목에서 신선한 20문항 진단 세트를 1회씩 확보

권장 비중: **교재 80 / 기출 20**

### T-21 ~ T-15: 교재와 기출 병행

- 하루 최소 단위는 여전히 복습 또는 신규 1페이지
- 추가 학습의 상당 부분을 과목별 20문항에 사용
- 기출 오답을 교재 복습 큐로 역연결
- 60점 미만 과목을 위험 과목으로 표시

권장 비중: **교재·복습 60 / 기출 40**

### T-14 ~ T-8: 기출 우세 구간

- 신규 페이지는 빈틈을 메우는 용도로만 진행
- 매일 가능하면 현재 대상 과목의 신선한 20문항 세트 수행
- 60점 미만 과목을 최우선 보강
- 이미 70점 이상인 과목은 유지 수준으로만 접촉

권장 비중: **교재·복습 30 / 기출 70**

### T-7 ~ T-3: 실전 점수 검증

- 최소 2회는 100문항 전체 모의 형태로 검증
- 가능하면 실제 시험 시간 2시간 30분에 맞춘다.
- 모의시험 사이 날에는 가장 낮은 과목의 20문항 + 오답 복습
- 신규 교재 진도는 원칙적으로 중단하고 점수에 직접 연결되는 빈틈만 확인

권장 비중: **교재·복습 20 / 기출·모의 80**

### T-2 ~ T-1: 안정화

- 신규 페이지 시작 금지
- 남아 있는 복습 큐 정리
- 반복 오답, 숫자, 순서, 조건, 법규 요건 중심 확인
- 점수가 불안한 과목만 가벼운 20문항 검증
- 새 개념을 대량 추가하지 않는다.

## 9. 하루 대상 결정 알고리즘

코치는 매일 사용자가 과목을 고르게 하지 않고 다음 순서로 1단위를 결정한다.

1. 복습 큐에 전날 실패 항목이 있으면 가장 오래된 복습 항목을 지정한다.
2. 복습 항목이 없으면 신규 진도 격차를 확인한다.
3. 가장 뒤처진 과목이 있으면 그 과목을 우선한다.
4. 격차가 동일하면 `rotation_cursor`의 과목을 선택한다.
5. T-21 이후 위험 점수 과목이 있으면 추가 단위는 그 과목의 오답·기출을 우선한다.
6. 한 과목의 신규 진도가 최소 과목보다 2단위 앞서게 되는 선택은 금지한다.
7. 수행 결과를 기록한 뒤 다음 포인터를 자동 갱신한다.

따라서 사용자는 매일 **“오늘 대상 알려줘”**라고만 해도 된다.

## 10. 기록 규격

학습 기록은 하루가 아니라 **1단위당 1레코드**로 누적한다. 같은 날 여러 단위를 수행하면 여러 레코드가 생긴다.

필수 필드:

- 날짜
- 과목
- 페이지
- 단위 유형: 신규 / 복습 / 기출 / 모의
- 7회독 완료 여부
- 회상 요약
- 검증 결과
- 오류·누락
- 복습 필요 여부
- 복습 통과 여부
- 과목별 누적 진도

기출 단계부터 추가 필드:

- 기출 세트 식별자
- 신선 문제 여부
- 정답 수 / 20
- 점수
- 오답 유형
- 관련 복습 페이지 또는 개념

과목별 누적 상태는 매 레코드 처리 후 다음 형태로 갱신한다.

```text
시스템보안: 신규 완료 N / 복습 대기 N / 최근 신선 점수 N
네트워크보안: 신규 완료 N / 복습 대기 N / 최근 신선 점수 N
어플리케이션보안: 신규 완료 N / 복습 대기 N / 최근 신선 점수 N
정보보안일반: 신규 완료 N / 복습 대기 N / 최근 신선 점수 N

```

## 11. 최초 1회 설정

실제 학습 시작 전에 다음만 한 번 설정한다.

1. 사용 교재명과 판본
2. 교재 목차 또는 5과목별 페이지 범위
3. 각 과목의 시작 페이지
4. 기출문제 출처
5. 시험일까지 남은 일수

이 설정이 끝나면 각 과목의 `next_page`와 회전 포인터를 초기화한다. 이후 사용자는 페이지 선택을 고민하지 않는다.

## 12. 운영 핵심 요약

- **하루 최소는 1페이지다.** 1페이지를 했으면 시스템 연속성은 유지된다.
- **1페이지는 7회독 후 반드시 책을 덮고 회상한다.**
- **회상은 코치 검증을 통과해야 완료다.**
- **틀리면 다음 신규 진도보다 복습이 먼저다.**
- **5과목 신규 진도 격차는 1단위 이내로 유지한다.**
- **추가 시간은 다음 과목 또는 위험 과목에 사용한다.**
- **T-21부터 기출 비중을 본격적으로 올리고, T-14부터 기출이 교재보다 우세해진다.**
- **T-7부터는 실제 합격 가능성을 20문항 과목 점수와 100문항 모의로 검증한다.**
- **실제 과락선 40점에 맞추지 않고 과목별 60점 이상을 운영 최소선으로 삼는다.**
- **사용자는 수행과 회상만 담당하고, 과목 선택·상태 갱신·복습 큐·누적 진도는 코치가 관리한다.**
