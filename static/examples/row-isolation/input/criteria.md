# 공개 판정 기준 (가상 실험용, 직접 작성)

> 이 기준은 실험을 위해 새로 쓴 일반 기준이다. 특정 고객·제품·보고서에서 가져오지 않았다.

## 공통 규칙
- 판정값은 `양호`, `취약`, `수동진단` 중 하나만 쓴다.
- 판정 근거는 **그 행에 적힌 수집 결과·답변·증적 설명만** 사용한다.
- 조회가 실패했거나 근거가 없으면 `수동진단`으로 둔다. 조회 실패를 양호로 두지 않는다.
- "앞 장비와 같음"처럼 다른 대상을 가리키는 답변은 그 행의 근거가 아니다.

## X-01 쉘 세션 타임아웃
- 양호: 쉘 세션 타임아웃(TMOUT)이 600초 이하로 설정됨
- 취약: TMOUT이 설정되지 않았거나 600초를 초과함
- 수동진단: 설정 파일을 읽지 못해 값을 확인할 수 없음

## X-02 불필요 계정 관리
- 양호: 사용하지 않는 계정을 삭제하거나 잠근 사실이 그 행의 답변 또는 증적 설명으로 확인됨
- 취약: 사용하지 않는 계정이 잠기지 않고 남아 있음이 확인됨
- 수동진단: 그 행에 계정 관리 사실을 확인할 근거가 없음
