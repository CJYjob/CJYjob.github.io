# 행 단위 판정 격리 합성 실험 (synthetic)

모든 입력은 이 실험을 위해 처음부터 만든 가상 자료입니다. 실제 고객사·자산·설정·판정값은 들어 있지 않습니다.

## 무엇을 비교했나
- A안: 한 번의 실행에서 R1부터 R5까지 순서대로 판정 (A_sequential)
- B안: 행마다 새 실행, 그 행과 공개 기준만 입력 (B_R1부터 B_R5)
- 변형: 기준에서 "다른 대상을 가리키는 답변은 근거가 아니다" 문장을 뺀 A2_sequential_noXrule, B2_R5_noXrule

가상 행 5개:
- R1·R2·R3: 같은 항목(세션 타임아웃)인데 값이 600, 3600, 읽기 실패로 서로 달라 결론이 달라야 함
- R4: 계정 잠금 답변과 증적 설명이 있음
- R5: R4와 같은 계정 목록, 답변은 "앞 장비와 동일합니다"뿐. R4 사실을 끌어오면 오판정

## 실행 기록
| 항목 | 내용 |
|---|---|
| 모델 | claude-opus-5-5 (8개 실행 모두, 실행 기록의 model 필드로 확인) |
| 서비스 | Claude Code(VS Code 확장)의 서브에이전트 기능, general-purpose 유형 |
| 실행일 | 2026-11-11, 8개를 동시에 시작(14:46 KST 무렵) |
| 실행 횟수 | 조건마다 1회 |
| 실행 방법 | prompts 폴더의 글을 그대로 각 서브에이전트의 첫 입력으로 넣고, 응답 원문을 output 폴더에 저장 |
| 온도 등 샘플링 설정 | 미확인(도구가 노출하지 않음) |

## B안이 독립 컨텍스트였다는 근거
- 서브에이전트마다 새 대화로 시작한다. 앞선 다른 실행의 응답을 받지 않는다.
- 실행 기록상 각 B 실행의 입력에는 자기 행 하나만 있었다(R1 실행에는 "### 행 R1"만 등장). prompts/manifest.json의 rows_in_prompt도 같다.
- 어느 실행도 파일 읽기나 검색 도구를 쓰지 않았다. 도구 호출은 결과 반환 1회뿐이었다.
- 한계: 이 서브에이전트는 작업 폴더의 공통 지침(판정과 무관한 작업 환경 설명)을 자동으로 함께 받는다. 완전히 빈 컨텍스트는 아니다. A안과 B안이 같은 조건이라 비교에는 영향이 같다.

## 정답을 실행 전에 정했다는 근거
- input/expected.json 수정 시각 14:44:45, 프롬프트 생성 14:45:01, 실행 시작 14:46:18, 응답 저장 14:46:48 (모두 2026-11-11 KST).
- 수정 시각은 로컬 파일 속성이라 강한 증거는 아니다. 작업 대화 기록의 순서도 같다.

## 재현 순서
1. `python -I build_prompts.py` : input에서 prompts의 A·B 프롬프트와 manifest.json을 다시 만든다. A2·B2 변형은 기준에서 위 금지 문장 한 줄만 지운 것이며 이 스크립트로 만들지 않는다(파일은 prompts에 있음).
2. 새 모델로 다시 실행하려면 각 프롬프트를 새 대화에 붙이고 응답 JSON을 같은 이름으로 output에 저장한다.
3. `python -X utf8 -I grade.py` : output의 응답을 채점해 output/grade_result.json을 다시 쓴다. Windows 콘솔에서 한글이 깨지면 -X utf8을 붙인다.

## 채점 기준
- 일치: 판정이 expected.json과 같은가
- 밝힌 참조: 응답의 referenced_rows가 비어 있는가
- 근거 속 다른 행: basis에 자기 아닌 R1-R5 표기가 있는가
- R4 사실 전이: R5 근거에 R4에만 있는 잠금 사실(잠금·잠김·잠근)이 "없다"는 말 없이 들어갔는가

## 재채점 결과 (2026-11-11, 저장된 응답으로 재실행)
- 16개 행 판정 모두 정답과 일치
- 밝힌 참조, 근거 속 다른 행, R4 사실 전이 모두 0건
- A안과 B안 사이에 차이 없음

## 이 실험이 시험한 것과 못 한 것
시험한 것:
- 신호가 분명한 짧은 입력에서, 같은 실행 안의 앞 행 판정이 뒤 행 판정을 끌고 가는지

시험하지 못한 것:
- 행 수가 많고 앞 판정이 긴 대화에 쌓인 경우
- 근거가 애매한 행, 증적 이미지가 있는 행
- 반복 실행에서의 흔들림(조건마다 1회)
- 스크립트로 앞 행 판정을 일부러 복사하는 경우. 이것은 모델 컨텍스트 편향과 다른 현상이라 이 실험 범위 밖이다.

결론: 모든 조건이 정답이어서, 이 실험은 행별 격리의 효과를 입증하지 못했다. "격리가 필요 없다"는 근거로도 쓸 수 없다.

## 과거 실무 작업과의 관계
- 과거 실무에서는 행별 입력 묶음을 만들었지만, 판정은 한 대화 안에서 여러 행을 함께 보며 했고 행마다 격리하지 않았다.
- 과거에 생긴 다른 행 결론의 전이는 같은 유형 행에 앞 판정을 스크립트로 복사한 명시적 선례 적용이었다. 모델이 앞 내용에 끌리는 컨텍스트 편향과는 다른 현상이다.
- 이 합성 실험은 과거 작업과 별개다. 과거 작업의 품질이나 성과를 보여주는 자료가 아니다.

## 집필 측 재검토
모델 표기는 전달받은 조사 문서의 기록이다. 이 묶음에는 원본 모델 실행 로그를 포함하지 않아 집필 측이 모델 식별자를 독립 검증하지 못했다. 저장 응답의 재채점 결과는 직접 확인했다.
