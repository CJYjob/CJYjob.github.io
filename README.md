# CJYjob.github.io

# 인생 관리 · 커리어 종합 정리

> 진행 순서: 블로그 이해(1) → AI 개념(2) → 하네스(3) → 모바일 앱(3 결과물)

## 1. 기록 시스템 (블로그 + 모바일 + 습관 강제)

- **블로그 구축**: 인생 전반 기록용 블로그 체계화, 노션 → GitHub Pages 이전 (개발 역량 목적)
- **직접 관리 역량**: AI가 만든 블로그를 스스로 관리, 작업 워크플로 이해, Hugo 연동 구조 이해
- **통합 허브**: 대부분의 기록·활동을 블로그로 통합
- **모바일 중심 운영**: 항상 지니는 휴대폰으로 기록·확인·관리
  - 모바일 앱으로 블로그를 가볍게 확인·기록 (앱 개발은 3번에서)
- **습관 강제 시스템**
  - 알라미 방식(미션 수행해야 해제) 벤치마킹, 우회 방지 구조로 개발
  - 모바일펜스류 벤치마킹 → SNS 등 유혹 차단
  - 시간마다 활동 기록 강제, 주기적으로 기록 확인·정리 → 강제 습관 형성

## 2. AI 학습 (개념·트렌드·ARTEX)

- **AI 활용도 향상**: AI를 더 적극 활용
- **개발 원리 이해**: AI 서비스 개발 방식, 최신 트렌드 파악
- **핵심 개념**: 모델 · 에이전트 · 하네스 구조 이해
- **ARTEX 연구**: AI 레드팀 도구의 개념·구조 학습 (공격 도구로서의 동작 + 탐지·방어 관점 모두)
  - 비공개 전환됐으나 clone본으로 학습 가능

## 3. AI 개발 (하네스 · 코치 · 모바일 앱)

- **AI 코치 재제작**: 기존 GPTs 코치들을 학습한 AI 하네스 형태로 전환
- **모바일 앱 개발**: 하네스를 담아 블로그를 가볍게 확인·기록하는 앱
  - 1번 "모바일 중심 운영"을 실현하는 수단 (블로그·AI 이해 후 착수)
- **보안 자동화 개발**: AI 활용 보안 도구/자동화 직접 개발
- **GPTs 플러그인 전환 대응**: 기존 GPTs 적용 내용 파악, 플러그인 변경 방식·유지 여부 판단 (가능하면 하네스·모바일 앱 구축 후 이전)

## 4. 보안 레드팀 역량 / CVE

- **레드팀 역량 확보**: AI 레드팀 도구 구조 이해 기반으로 실전 역량 구축
- **CVE 취득**
- **퍼징 자동화 경험**: AI를 퍼징 오케스트레이터로 활용해 크래시 탐색

## 5. 이직 준비

- **이력서** 수정
- **포트폴리오** 정리
- **경력 회고**: 과거 이력 되짚어 디벨롭, AI로 업무 이력 정리
- **블로그 자산화**: 정리한 이력을 블로그 콘텐츠로

## 6. 자격증

- **단기:** 정보보안기사, CPPG
- **장기(2년 후):** 정보관리기술사, 컴퓨터응용시스템기술사
- **기타:** ISMS 인증 심사원, 소프트웨어 감리사 (그 외 자격증은 기술사 범위 중복 여부로 판단)

## 7. 영어

- 강성태 영문법·영단어 책 활용
- 매일 영문법 5문장 + 등장 단어 어원까지 암기

## 8. 운동

- 매일 40분: 웜업 3분 → 무산소 20분(하드) → 유산소 → 스트레칭 5분
- 유산소: 15km/h로 3km를 12분에 완주 목표
- 근력: 가슴 / 등 / 하체 3분할
